ℹ️ About This Validator

This JavaScript validator provides the same functionality as the Python script validate_screens.py, but runs entirely in the browser.

Features:

  • ✅ Schema validation for screen data
  • ✅ Type checking for all fields
  • ✅ Business logic validation (positive numbers, valid colors)
  • ✅ Duplicate detection
  • ✅ Nested object validation (projection, sound_system)
  • ✅ Detailed error reporting
  • ✅ Browser-compatible (no Python dependency)

Validation Types:

  • Missing Field: Required fields are absent
  • Type Error: Field has wrong data type
  • Business Logic: Values don't meet business rules
  • Duplicate: Same screen appears multiple times
